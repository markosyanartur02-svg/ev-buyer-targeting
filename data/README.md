# Data

The data is not included in this repository. Download it from the
[competition data page](https://www.kaggle.com/competitions/playground-series-s6e9/data)
and place the files here:

```
data/
├── train.csv
├── test.csv
├── sample_submission.csv
└── original/
    └── EV_Adoption_and_Range_Anxiety_Dataset.csv   # 10,000-row reference dataset (optional)
```

The reference dataset is only needed for `exp_orig.py`; it is available
[here](https://www.kaggle.com/datasets/itzzomkar/ev-adoption-behavior-and-range-anxiety).
